# 分类映射树形对照页设计

- 日期：2026-08-15
- 状态：已实现并通过静态与浏览器回归
- 适用范围：拾马商城平台运营后台一期静态原型

## 1. 业务目标

将分类映射页的表格替换为左右树形对照，让供货运营人员同时看到平台商品分类、当前集采平台来源分类及两者关系，减少在“来源路径”和“目标路径”两列之间反复比对的成本。

成功标准：当前平台、查询条件、分类层级、映射方向和每条关系的产品数量可以在同一屏内识别。

## 2. 页面结构

页面从上到下固定为四层：

1. 页面说明与导入记录、导出关系、导入映射操作。
2. 京选集采、企采云、华采供应链平台页签。
3. 来源关键字、映射状态、来源状态查询表单。
4. 左右树形对照区。

左右树形对照区使用以下对象归属：

| 区域 | 对象 | 规则 |
|---|---|---|
| 左侧 | 平台商品分类树 | 复用商品管理的两级树形样式，不展示“全部”节点 |
| 中间 | 映射关系 | 箭头从右侧来源二级分类指向左侧平台二级分类；中部显示产品数量 |
| 右侧 | 当前集采平台来源分类树 | 来源一级分类只分组，来源二级分类才参与映射 |

## 3. 展示规则

- 平台页签切换后，右侧来源树、关系线、数量标签和查询结果同步切换；左侧平台分类树保持同一套平台分类。
- 查询条件只过滤右侧来源二级分类及其对应关系；父级路径保留用于解释层级。
- 已映射关系使用蓝绿色实线和左向箭头；来源失效仍保留关系，但降低线条透明度。
- 未映射来源分类不绘制关系线，节点展示“未映射”。
- 一个平台二级分类可接收多条来源关系；每条关系独立显示自己的产品数量。
- 映射区不展示商品明细、商品图片、缩略图或批量选择。
- 页面不新增“冲突”“待确认”等业务状态。

## 4. 交互

- 平台一级分类与来源一级分类支持独立展开、收起，不改变商品管理页面的树状态。
- Hover 或键盘聚焦来源二级分类时，仅强化该来源、目标和对应关系，其他关系降低透明度。
- 来源二级分类保留设置映射、修改映射、查看历史和产品数量下钻入口。
- 映射保存或解除后重新渲染左右树与关系线；原有版本校验、解除确认和导入流程保持不变。
- 页面尺寸变化或树节点展开收起后重新计算关系线路径。

## 5. 响应式与可访问性

- 1440px 下左右树为主要宽度，中间关系区保持数量标签可读。
- 1024px 下仍保持左右对照，不产生页面级横向滚动；节点长文本省略并通过 `title` 暴露完整路径。
- 映射状态同时使用颜色、文字和线型，不依赖颜色作为唯一信息。
- 可操作节点和按钮保留键盘焦点；关系 SVG 为展示性内容，不进入焦点顺序。

## 6. 不在本次范围

- 拖拽建立映射。
- 商品明细和商品图片预览。
- 批量映射、多选或跨平台操作。
- 修改映射数据模型、导入规则或来源商品归集规则。
