# 资金对账关键 KPI 看板设计

- 日期：2026-08-15
- 状态：已实现并通过静态与浏览器回归
- 适用范围：拾马商城平台运营后台一期静态原型
- 覆盖端：Web 平台运营后台；小程序、客户侧 API 和其他终端不增加入口

## 1. 业务目标

在资金对账页顶部同时呈现本月资金规模、当前余额快照与未闭环异常，让供货运营进入页面后无需先阅读逐平台对账记录，就能判断资金量级、账实差异及后续处理优先级。

成功标准：运营人员在同一屏内能够回答“本月采购了多少”“退款与调整了多少”“当前账面和接口余额是多少”“本月累计差异和待核对订单有多少”。

## 2. 用户故事

| 用户 | 需求 | 价值 |
|---|---|---|
| 供货运营 | 进入资金对账页后先查看本月关键指标 | 快速判断资金规模和对账健康度 |
| 财务复核人员 | 同时比较接口余额与账面余额 | 发现账实差异，无需逐行汇总 |
| 异常处理人员 | 查看差异平台和待核对订单提示 | 优先处理尚未闭环的问题 |

## 3. 页面结构

资金对账页从上到下调整为：

1. 页面说明及“立即校对”操作。
2. 关键 KPI 看板。
3. 原查询表单。
4. 原资金对账记录表格与分页。

本次只增加顶部概览，不修改查询、重置、立即校对、表格字段和分页流程。

## 4. KPI 定义

看板固定展示六项指标：

| KPI | 示例主值 | 统计口径 | 辅助信息 |
|---|---:|---|---|
| 本月采购金额 | ¥1,246,580 | 当前自然月成功采购成本之和 | 已覆盖 3 个供货平台 |
| 本月退款与调整 | ¥32,460 | 当前自然月已入账退款金额与人工调整金额之和 | 退款 16 笔、调账 2 笔 |
| 当前接口余额 | ¥547,880 | 各供货平台最近一次余额接口查询值之和 | 最近校对 08-15 14:28 |
| 当前账面余额 | ¥547,760 | 各供货平台当前理论余额之和 | 按理论余额公式计算 |
| 本月累计差异 | ¥120 | 当前自然月新增且已确认的差异事件绝对值之和 | 1 个平台存在差异 |
| 待核对订单 | 2 笔 | 当前仍未完成资金归因或订单统计核对的订单数 | 最长待处理 2 小时 18 分 |

理论余额继续沿用一期 PRD 公式：期初余额＋充值－成功采购成本＋退款与调整。

## 5. 数据与边界规则

- “采购金额、退款与调整、本月累计差异”按当前自然月累计；月初自动切换新周期。
- 同一未解决差异在重复校对中只累计一次；差异解决后不冲减本月累计值，当前未解决范围由辅助信息表达。
- “接口余额、账面余额”属于当前存量快照，不按月累计；辅助信息必须说明最近查询时间或计算依据。
- “待核对订单”使用当前未闭环数据，不受自然月边界影响，避免跨月异常被隐藏。
- 本月无业务时，月累计金额显示 `¥0.00`，不显示空白或 `--`。
- 尚未获得任何平台接口余额时，“当前接口余额”显示 `暂未获取`，辅助信息提示执行立即校对；不得将缺失余额按零计入。
- 部分平台查询失败时，接口余额只汇总成功返回的平台，并展示“2/3 个平台已更新”，避免把不完整数据表达为完整余额。
- 金额统一使用人民币符号、千分位和两位小数；订单与平台数量使用整数。
- 所有指标沿用当前租户和数据权限范围，不跨租户汇总。

## 6. 视觉设计

- 使用六张等宽 KPI 卡片；1440px 下单行六列，1024px 下每行三列。
- 卡片结构固定为“指标名称—主值—辅助说明”，主值使用等宽数字特征，便于横向比较。
- 本月采购金额、接口余额和账面余额使用品牌蓝或绿色；退款与调整使用橙色；累计差异和待核对订单使用红色。
- 颜色只表达风险强弱，指标名称、主值和辅助文字必须独立传递含义，不以颜色作为唯一状态标识。
- 看板保持紧凑，不增加趋势图、环比图或独立筛选器，避免与渠道经营分析页重复。

## 7. 交互与反馈

- 当前阶段 KPI 卡片只读，不新增卡片点击跳转，防止产生未定义的筛选联动。
- 点击“立即校对”继续沿用现有反馈；静态原型不伪造接口请求完成后的实时数据刷新。
- 查询表单仍只作用于下方对账记录，不改变顶部全局 KPI，避免局部查询条件造成总体指标误读。

## 8. 异常场景

| 场景 | 展示规则 |
|---|---|
| 全部平台余额查询成功 | 展示完整接口余额及最近校对时间 |
| 部分平台余额查询失败 | 汇总成功平台，并明确成功平台数 |
| 全部平台尚未查询 | 接口余额显示“暂未获取”，引导立即校对 |
| 跨月待核对订单仍未关闭 | 继续计入“待核对订单” |
| 同一差异被多次校对发现 | 只按首次确认的差异事件累计一次，不重复计数 |
| 用户无某平台数据权限 | 该平台不进入金额、余额、平台数量或异常数量汇总 |

## 9. 验收标准

- 页面说明与查询表单之间恰好展示一个 KPI 看板。
- 看板完整展示六项指标及辅助信息。
- 月累计指标与余额快照在文案中有明确区分。
- 1440px 下六张卡片保持单行，1024px 下排列为两行三列且无页面级横向滚动。
- 差异与待核对指标同时使用风险色和文字说明。
- 原查询、重置、立即校对、表格与分页流程不受影响。
- PRD、静态合约测试与浏览器视觉测试同步更新。

## 10. 不在本次范围

- KPI 卡片下钻或联动筛选。
- 自定义统计周期或跨月趋势。
- 新增对账数据模型、真实余额接口调用或自动刷新机制。
- 修改理论余额公式、差异确认规则或订单对账状态机。
