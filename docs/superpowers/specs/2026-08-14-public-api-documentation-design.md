# 公开 API 文档页面设计

- 日期：2026-08-14
- 产品：拾马商城
- 状态：方案与静态原型 UI 已实施并通过回归验证
- 适用范围：平台后台一期“系统管理 / API文档”及外部公开文档页

## 1. 业务目标

为 API 供货客户提供一套无需登录拾马商城后台即可访问的标准接口文档，降低商务交付和客户联调成本。平台运营只需复制一个长期有效的公开链接，无需逐客户创建分享记录、配置密码或维护有效期。

成功标准：

- 平台运营可以从系统管理找到 API 文档入口并复制公开链接。
- 外部客户打开链接后直接看到完整文档，不进入后台登录流程。
- 所有 API 客户查看同一套标准文档，不按企业生成副本。
- 页面不泄露任何客户 AppKey、Secret、Token 或内部后台信息。
- 桌面端和移动端均能完成目录定位、内容搜索和接口阅读。

## 2. 用户故事

| 用户 | 用户故事 | 验收结果 |
|---|---|---|
| 平台运营 | 我希望在后台找到统一 API 文档并复制公开链接，以便直接发送给 API 客户 | 两步内完成预览或复制链接 |
| API 客户开发人员 | 我希望无需后台账号即可查看接入说明和完整接口目录 | 打开公开链接后直接进入文档正文 |
| 平台产品与研发 | 我希望所有客户始终看到同一版本，避免多份文档口径不一致 | 公开链接只指向一个固定文档页面 |

## 3. 范围与边界

### 3.1 一期包含

- 系统管理新增二级菜单“API文档”。
- 后台 API 文档信息页。
- 独立外部公开 API 文档页。
- 后台预览、复制公开链接。
- 外部文档目录导航、关键字搜索、接口章节展示和移动端适配。
- 固定标准文档内容，所有访问者查看同一版本。

### 3.2 一期不包含

- 文档可视化编辑器或 Markdown 编辑器。
- 分享密码、有效期、停用开关和分享记录。
- 按 API 客户生成专属文档或专属链接。
- 外部访问账号、登录、短信验证或客户鉴权。
- 外部访问次数、访问日志和行为分析。
- 在文档中展示任何真实客户凭证。
- 自动从 OpenAPI 文件、代码注解或接口网关生成文档。

## 4. 信息架构

后台菜单调整为：

```text
系统管理
├── 用户管理
├── 角色权限
└── API文档
```

页面关系：

```text
系统管理 / API文档
├── 预览公开文档 ──→ 独立公开文档页（新窗口）
└── 复制公开链接 ──→ 剪贴板 ──→ API客户直接访问
```

“API文档”仍是后台菜单权限的一部分。是否可以维护后台用户、角色，与是否可以访问外部公开文档无关；外部页面本身不执行后台菜单权限校验。

## 5. 后台 API 文档页面

### 5.1 页面职责

后台页面只承担“找到文档、确认当前版本、预览、复制链接”四项职责，不承担内容编辑或分享管理。

### 5.2 页面布局

沿用当前后台规范：不显示重复大标题，保留左上角灰色提示词。

页面结构：

1. 灰色提示词：`API客户统一访问同一套公开接口文档；链接长期有效，请勿在文档中填写客户密钥。`
2. 右上角操作：`预览公开文档`、`复制公开链接`。
3. 文档信息卡：公开地址、当前版本、最近更新时间、文档状态。
4. 目录概览：展示十个固定章节及其内容数量，便于运营确认文档覆盖范围。
5. 安全提示：只说明公开页面不得出现凭证，不使用大面积规则提示条。

### 5.3 字段与交互

| 字段/操作 | 展示或行为 |
|---|---|
| 公开地址 | 显示固定外部路径，支持选中但不在地址中携带客户参数 |
| 当前版本 | 展示静态文档版本，例如 `v1.0` |
| 最近更新时间 | 展示文档代码最后更新时间 |
| 文档状态 | 固定展示“公开访问” |
| 预览公开文档 | 在新窗口打开独立外部页面 |
| 复制公开链接 | 复制固定 URL，成功后显示轻提示 |

“复制公开链接”失败时提示用户手工复制地址，不改变页面状态。

## 6. 外部公开文档页面

### 6.1 页面边界

外部页面不复用后台壳层，不展示后台侧边栏、顶部工具栏、账号头像、客户资料或后台面包屑。页面品牌固定为“拾马商城开放接口文档”。

### 6.2 桌面端布局

- 顶部：产品标识、文档版本、全文搜索。
- 左侧：固定目录树，显示章节和接口条目。
- 中间：章节说明、接口地址、请求方法、参数、请求示例、响应示例、状态说明。
- 右侧或正文内：当前章节锚点和复制代码按钮。
- 滚动正文时同步高亮当前目录项。

### 6.3 移动端布局

- 顶部保留产品名称、目录按钮和搜索入口。
- 左侧目录收拢为抽屉，不长期占据屏幕宽度。
- 参数表支持横向滚动，代码块支持复制。
- 不把桌面三栏结构按比例缩小。

### 6.4 固定文档目录

1. 接入说明与鉴权。
2. 商品分类与商品/SKU查询。
3. 收货地址、实时库存与运费查询。
4. 创建订单。
5. 订单查询与状态说明。
6. 物流查询。
7. 取消订单与异常处理。
8. 账户余额查询。
9. 回调通知与幂等规则。
10. 公共错误码与联调示例。

每个接口条目统一包含：

| 区块 | 内容 |
|---|---|
| 接口摘要 | 名称、用途和调用时机 |
| 调用信息 | 请求方法、接口路径、Content-Type |
| 请求参数 | 参数名、位置、类型、是否必填、说明、示例 |
| 请求示例 | JSON 或 Query 示例，提供复制按钮 |
| 响应参数 | 字段名、类型、说明 |
| 响应示例 | 成功与典型失败示例 |
| 业务规则 | 幂等、重试、状态传递和边界说明 |

本轮 UI 原型中的路径和示例用于表达文档结构，不作为生产接口已经发布的证明；正式对外前必须由研发以真实接口合同逐条替换和校验。

## 7. 核心操作流程

### 7.1 运营分享

1. 运营进入“系统管理 / API文档”。
2. 查看当前版本、更新时间和目录覆盖。
3. 可先点击“预览公开文档”检查页面。
4. 点击“复制公开链接”。
5. 系统复制固定公开 URL 并给出成功提示。
6. 运营通过现有商务沟通渠道发送链接。

该流程不创建分享记录，也不关联 API 客户数据。

### 7.2 客户访问

1. 客户打开公开链接。
2. 浏览器直接加载标准文档页。
3. 客户通过目录或搜索定位接口。
4. 客户查看参数、示例、状态和异常规则。
5. 客户复制请求或响应示例用于联调。

## 8. 页面状态与异常

| 场景 | 页面处理 |
|---|---|
| 文档正常加载 | 展示完整目录和默认“接入说明与鉴权”章节 |
| 搜索无结果 | 展示“未找到匹配接口”，保留清空搜索入口 |
| 目录锚点不存在 | 回到文档顶部，不展示空白页 |
| 复制链接成功 | 后台轻提示“公开链接已复制” |
| 浏览器拒绝剪贴板 | 提示“复制失败，请手工复制公开地址” |
| 复制代码成功 | 外部页面按钮短暂切换为“已复制” |
| JavaScript 不可用 | 文档正文仍可阅读，仅搜索、目录高亮和复制功能不可用 |
| 移动端表格过宽 | 参数表区域横向滚动，不压缩文字到不可读 |

公开页面长期有效且不提供停用能力。如果未来需要控制访问，必须另立需求增加鉴权或链接治理，不能通过临时隐藏按钮假装完成访问控制。

## 9. 数据与技术边界

一期为纯静态原型：

- 后台 API 文档页沿用现有 `admin.html` 单页渲染方式。
- 外部文档使用独立 `api-docs.html`，不加载后台导航状态和角色数据。
- 公开 URL 在原型中使用相对路径 `api-docs.html`，正式部署时由部署环境配置为公开域名地址。
- 文档内容直接维护在外部页面代码中。
- 后台菜单权限树新增 `api-docs` 菜单编码，只控制内部入口显示。
- 外部页面不调用后台用户、角色、企业、订单或账户数据接口。

正式开发时如果继续采用长期公开模式，Web 服务器必须允许匿名读取文档静态资源，并禁止在构建产物中注入真实密钥。

| 预览与复制公开链接 | MVP 必做 | S |

## 11. 验收标准

1. 系统管理菜单包含“API文档”，角色菜单权限树同步出现该菜单。
2. 后台 API 文档页不出现查询列表、分享记录、密码、有效期或停用配置。
3. 后台可在新窗口预览外部文档，并可复制固定公开链接。
4. 外部链接无需后台账号或密码即可直接访问，且长期有效。
5. 外部页面不显示后台导航、客户信息或任何真实 AppKey、Secret、Token。
6. 外部页面完整展示已确认的十个章节。
7. 接口条目具备请求参数、响应参数、示例、状态和异常规则的统一结构。
8. 目录点击、全文搜索和代码复制可用；搜索无结果有明确反馈。
9. 桌面端使用目录与正文布局，移动端使用目录抽屉且参数表可横向滚动。
10. 关闭 JavaScript 后文档正文仍可阅读。
11. 当前后台、小程序、系统用户和角色权限原型回归不受影响。
