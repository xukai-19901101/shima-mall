01

接入说明与鉴权

服务端调用业务接口前获取短期访问令牌；应用凭证由商务开通后通过安全渠道单独交付，不在公开文档中展示。

POST/openapi/v1/auth/token

在首次调用或令牌过期前触发。令牌只用于服务端请求，不得下发到浏览器或小程序端。

请求参数

参数类型必填说明示例
app_keyString是平台分配的应用标识YOUR_APP_KEY
timestampLong是秒级 Unix 时间戳，允许误差 5 分钟1786694400
request_idString是调用方生成的唯一请求号YOUR_REQUEST_ID
signatureString是按签名规则计算的摘要YOUR_SIGNATURE

请求示例

{
  "app_key": "YOUR_APP_KEY",
  "timestamp": 1786694400,
  "request_id": "YOUR_REQUEST_ID",
  "signature": "YOUR_SIGNATURE"
}

响应示例

{
  "code": "SUCCESS",
  "data": {
    "access_token": "YOUR_ACCESS_TOKEN",
    "expires_in": 7200
  }
}
02

商品分类与商品/SKU查询

拉取平台开放分类和可供货商品。商品只返回当前客户可见范围，分类与商品状态变化后以最新查询结果为准。

GET/openapi/v1/categories

获取平台两级商品分类。返回值仅包含当前可用的分类节点。

请求参数

参数位置类型必填说明
updated_afterQueryString否只返回指定时间后更新的分类
AuthorizationHeaderString是Bearer YOUR_ACCESS_TOKEN

响应示例

{
  "code": "SUCCESS",
  "data": [{
    "category_id": "CAT-DIGITAL-01",
    "parent_id": "CAT-DIGITAL",
    "name": "键鼠外设",
    "level": 2,
    "status": "ENABLED"
  }]
}
GET/openapi/v1/products/{sku_id}

查询单个 SKU 的名称、规格、结算价和当前可售状态。价格为当前请求客户的动态结算结果。

响应示例

{
  "code": "SUCCESS",
  "data": {
    "sku_id": "SKU-10284-02",
    "product_name": "无线蓝牙键盘 K3",
    "settlement_price": 238.00,
    "sale_status": "ON_SALE",
    "updated_at": "2026-08-14T18:00:00+08:00"
  }
}
03

收货地址、实时库存与运费查询

集采商品库存与收货地址相关。创建订单前必须以实际地址查询实时库存，再查询对应运费。

POST/openapi/v1/inventory/query

提交实际收货区域和 SKU 数量，返回当前可售数量。查询结果仅用于下单前校验，不形成库存预占。

请求参数

参数类型必填说明示例
sku_idString是平台 SKU 编码SKU-10284-02
quantityInteger是计划购买数量，大于 02
province_codeString是省级行政区编码430000
city_codeString是市级行政区编码430100
district_codeString是区县行政区编码430104

响应示例

{
  "code": "SUCCESS",
  "data": {
    "sku_id": "SKU-10284-02",
    "available": true,
    "available_quantity": 83,
    "checked_at": "2026-08-14T18:12:06+08:00"
  }
}
POST/openapi/v1/freight/query

按实际收货地址和商品明细试算运费。运费结果应与创建订单使用相同地址和商品数量。

响应示例

{
  "code": "SUCCESS",
  "data": {
    "freight_amount": 12.00,
    "currency": "CNY",
    "valid_until": "2026-08-14T18:20:00+08:00"
  }
}
04

创建订单

库存与运费校验通过后提交订单。调用方订单号是幂等键，同一客户下必须保持唯一。

POST/openapi/v1/orders

平台受理后返回平台订单号和初始状态。响应超时时不得直接换新订单号重下，应先查询原调用方订单号。

请求参数

参数类型必填说明
client_order_noString是客户订单号，同一客户内唯一
receiverObject是收件人、手机号、行政区编码和详细地址
itemsArray是SKU 与购买数量，至少一项
callback_urlString否订单状态回调地址

请求示例

{
  "client_order_no": "CLIENT-ORDER-20260814-001",
  "receiver": {
    "name": "张先生",
    "mobile": "13800000000",
    "province_code": "430000",
    "city_code": "430100",
    "district_code": "430104",
    "address": "示例路 88 号"
  },
  "items": [{ "sku_id": "SKU-10284-02", "quantity": 2 }],
  "callback_url": "https://client.example.com/callback/orders"
}

状态起点

已受理→采购处理中→待发货
05

订单查询与状态说明

按调用方订单号查询平台受理、采购、履约和取消结果。查询接口是超时或回调缺失时的最终核对入口。

GET/openapi/v1/orders/{client_order_no}

返回订单主状态以及采购、履约等并行状态。调用方不得只依据物流字段推断采购是否成功。

响应参数

字段类型说明
order_statusString平台订单主状态
purchase_statusString上游采购状态
fulfillment_statusString发货与签收状态
failure_reasonString失败或异常原因，无异常时为空

响应示例

{
  "code": "SUCCESS",
  "data": {
    "client_order_no": "CLIENT-ORDER-20260814-001",
    "platform_order_no": "SM202608140001",
    "order_status": "PROCESSING",
    "purchase_status": "ACCEPTED",
    "fulfillment_status": "WAITING_SHIPMENT"
  }
}
06

物流查询

订单发货后查询包裹、承运商和物流轨迹。一个订单可能拆分为多个包裹。

GET/openapi/v1/orders/{client_order_no}/logistics

采购成功但尚未发货时返回空包裹数组，不视为接口失败。

响应示例

{
  "code": "SUCCESS",
  "data": {
    "packages": [{
      "package_no": "PKG-001",
      "carrier": "顺丰速运",
      "tracking_no": "SF_EXAMPLE_001",
      "status": "IN_TRANSIT",
      "traces": [{
        "time": "2026-08-14T17:20:00+08:00",
        "description": "包裹已由承运商揽收"
      }]
    }]
  }
}
07

取消订单与异常处理

订单是否可取消取决于采购和履约状态。取消请求被受理不代表最终取消成功，应继续查询或等待回调。

POST/openapi/v1/orders/{client_order_no}/cancel

仅允许取消尚未进入不可逆履约阶段的订单。重复取消同一订单返回当前取消结果。

请求参数

参数类型必填说明
reason_codeString是双方约定的取消原因编码
reason_noteString否补充说明，最多 200 字
request_idString是取消请求幂等号

异常处理

  • 响应超时：使用原订单号查询，不创建重复订单。
  • 采购结果未知：保持处理中，等待回调或主动查询。
  • 库存不足：订单不进入采购成功状态，按错误码提示客户。
08

账户余额查询

预存模式客户可查询当前人民币可用余额；月结客户返回授信额度和已用额度。余额仅用于资金校对。

GET/openapi/v1/account/balance

余额不足时平台可拒绝预存客户的新订单。调用方不应使用余额接口推断单笔订单最终结算状态。

响应示例

{
  "code": "SUCCESS",
  "data": {
    "settlement_mode": "PREPAID",
    "available_balance": 268780.00,
    "frozen_amount": 18600.00,
    "currency": "CNY",
    "queried_at": "2026-08-14T18:28:00+08:00"
  }
}
09

回调通知与幂等规则

订单状态变化后平台向客户登记的回调地址推送事件。客户必须按事件 ID 幂等消费，并返回明确成功响应。

POST{client_callback_url}

平台调用客户地址。非 2xx、网络超时或响应超时均视为失败，并按退避策略重试。

回调示例

{
  "event_id": "EVT-20260814-0001",
  "event_type": "ORDER_STATUS_CHANGED",
  "occurred_at": "2026-08-14T18:30:00+08:00",
  "data": {
    "client_order_no": "CLIENT-ORDER-20260814-001",
    "order_status": "SHIPPED"
  },
  "signature": "YOUR_CALLBACK_SIGNATURE"
}

幂等与重试

  • 客户使用 event_id 去重，重复事件返回成功。
  • 业务处理成功后返回 HTTP 200；不要先返回成功再丢弃处理结果。
  • 达到最大重试次数后，客户通过订单查询接口主动补偿。
10

公共错误码与联调示例

HTTP 状态表示传输结果，业务字段 code 表示具体处理结论。调用方应同时记录请求号和错误码。

GET/openapi/v1/errors

以下为原型中的代表性公共错误码，用于确认文档表达方式。

错误码

错误码含义是否可重试处理建议
AUTH_FAILED签名或令牌校验失败否检查凭证、时间戳和签名串
DUPLICATE_REQUEST幂等请求重复否使用原业务单号查询结果
INVENTORY_NOT_ENOUGH实际地址库存不足条件性调整数量或地址后重新查询库存
RATE_LIMITED超过调用频率限制是按响应中的等待时间退避
UPSTREAM_RESULT_UNKNOWN上游处理结果暂不明确否保持处理中并主动查询

失败响应示例

{
  "code": "INVENTORY_NOT_ENOUGH",
  "message": "当前收货地址可售数量不足",
  "request_id": "YOUR_REQUEST_ID",
  "data": {
    "sku_id": "SKU-10284-02",
    "available_quantity": 1
  }
}
